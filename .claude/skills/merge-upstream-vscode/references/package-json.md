## package.json files

package.json file conflicts are usually the result of Microsoft changing the
version of a dependency in the same region of the file where Positron has
_added_ a dependency.

In this example, Positron has _added_ the `ai-config`, `ai-credentials`, and
`ai-provider-bridge` dependencies, while Microsoft has updated the version of
the other dependencies. The correct resolution would be to keep the Positron
additions and update the Microsoft dependencies to the latest version.

# package-lock.json

package-lock.json files are autogenerated, but if you compile without cleaning
up the merge conflicts, then node will ignore the lockfile and regenerate it,
which is not what we want. Clean up the merge conflicts in the lockfile as you
would for a package.json file.
